# Model Engines

TensorRT engine files for the vision detection and segmentation models.

These files are excluded from the repo to keep it lean. They are available
as release assets or can be compiled from source.

## Download

| File | Size | Release |
|---|---|---|
| All 7 engines | ~175 MB | [v1.1 release](https://github.com/Unknownuserfrommars/booster-patch/releases/tag/v1.1) — Patch_1.1.zip |

## Usage

Copy the .engine files to Patch_1.1/src/vision/model/ before building.
Or download Patch_1.1.zip from the release which includes them.
